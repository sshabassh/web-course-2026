# Лабораторная работа №3. Основы JS и DOM: Todo-list

**Что сделано:** Реализован интерактивный список задач на чистом JavaScript. Состояние хранится в массиве объектов, рендеринг происходит через функцию `render()`. Реализованы добавление, удаление, отметка выполнения, фильтрация и счётчик.

**Как запустить:** Открыть `index.html` в браузере или перейти по ссылке GitHub Pages: [https://sshabassh.github.io/web-course-2026/task3/](https://sshabassh.github.io/web-course-2026/task3/)
